title: API keys
description: Generate keys for the Vern REST API and the MCP server.
---

API keys let your backend run customer migrations end to end without anyone logging into the dashboard, and let AI assistants like Claude Code or Cursor work in your account through Vern's [MCP server](/mcp/overview).

## Generate a key

Go to [Settings → API keys](https://app.vern.so/api-keys) and click **New key**. Give it a name (e.g. "Production server"), choose its **MCP access** (below), and create it. Copy the key — Vern doesn't show it again.

Treat it like a password. Don't commit it. Don't put it in client-side code. Use environment variables.

<Note>
  Creating and revoking keys is **Admin-only**. See [Team](/help-center/settings/team) for what each role can do.
</Note>

## MCP access

Each key has an **MCP access** setting that decides what an AI assistant using it may do through the [MCP server](/mcp/overview):

| Access | Lets the assistant |
|---|---|
| **Read** | Look up companies, templates, runs and knowledge. Always on. |
| **Write** | Create, change and run things (includes read). |
| **Delete** | Delete things, after a confirm step (includes read). |

Keys start as **Read**. To change a key's access, open its row's menu and click **Edit**. MCP access has no effect on the Migration API.

## Rotate or revoke

To revoke a key, open its row's menu and click **Delete**. Any request using that key fails immediately with a 401.

To rotate, create a new key, swap it in your environment, then delete the old one.

## Use it

Pass the key as an `x-api-key` header on every request:

```bash
curl https://app.vern.so/api/v1/migrations \
  -H "x-api-key: YOUR_KEY"
```

See the [Migration API quickstart](/migration-api/quickstart) for full setup.

## What keys let you do

- Create a migration — [`POST /api/v1/migrations`](/migration-api/create-a-migration) — then upload files, run the agent, and export clean data.

Workbook-export webhook payloads are signed separately via Svix, not authenticated with API keys — see [Webhooks](/help-center/send/webhooks).
